# STREAMFINDER
Este programa fue creado con el fin de poder "filtrar" peliculas segun tu preferencia, tiene un catalogo con 1500 peliculas distintas y el usuario puede elegir la manera mas conveniente para buscar peliculas de su gusto.

## Código a ejecutar 
Para ejecutar el programa se deben usar los siguientes codigos:
````
gcc tdas/*.c tarea22.c -Wno-unused-result -o tarea22
````
Y luego ejecutar:
````
./tarea22
````

## Funcionamiento
El programa no presento errores en funciones, por lo que no hay problema alguno para ejecutarlo.

## Ejemplo
>>gcc tdas/*.c tarea22.c -Wno-unused-result -o tarea22
>>./tarea22
>> 1 = carga la informacion
>> 4
>> 2900 = como no existe se muestra en pantalla el mensaje correspondiente, y pide digitar nuevamente una opcion (de la lista de opciones)
>> 4
>> 2000 = muestra por pantalla todas las peliculas de la decada del 2000
>> 0 = finaliza la ejecucion
